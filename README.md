# MINIMA LABS — Indian Clinical D2C Skincare Web App

Built with React, Vite, TypeScript, and Tailwind CSS. Inspired by brands like Minimalist and Nykaa.

## 🚀 Quick Start Locally

```bash
# 1. Install dependencies
npm install

# 2. Start development server
npm run dev
```

## 📦 Push to GitHub

```bash
git init
git add .
git commit -m "Initial commit: MINIMA LABS Indian Skincare D2C Web App"
git branch -M main
git remote add origin https://github.com/<your-username>/minima-labs.git
git push -u origin main
```

## 🌐 Deploy to Vercel

1. Go to [vercel.com](https://vercel.com) and log in with GitHub.
2. Click **Add New...** -> **Project**.
3. Select this repository and click **Deploy**.
